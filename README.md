# ImprovedSymbolsClassifier - models comparison

The project goal was to:
- Compare models from `scikit-learn` library and multilayer neural networks built with `tensorflow`
- Determine whether theese models are capable of distinguishing simple images
- Create model to use in real time in the [game](https://github.com/MateuszCzerniawski/VR_Escape_Room.git)
